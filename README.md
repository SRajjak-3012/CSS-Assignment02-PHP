# CSS-Assignment02-PHP

# HTML & CSS : 
Making a webpage containing ----
**Navbar** with Logo, Links & Button, 
**Main section** with class hero-container and diamond-grid-container.
The class **hero-container** consists with H1,Paragraph & a button. 
The class **diamond-grid-container** consist of a 2*2 Grid Box where 1 box with an Image and the others are colored as Background-color. 

All styling is done only with the CSS property including Grid-Box. For styling the Diamond box with Grid & Clip-path property of CSS.
**Grid** is used to Specify the position of the Diamond box by rotation & also give specific position of the only image containing in the specific box of the Diamond box by using Clip-path property. These both section is very tricky & most important section.
